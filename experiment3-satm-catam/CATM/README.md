# CATM

This folder contains the paper-facing entry point for the CATM evaluation.

- `run_catm.py`
  - validates and summarizes the packaged CATM results

CATM is the composition-level selective adaptation method used for the paper comparison.

For the reviewer packet, the precomputed CATM results used by the final table live in:

- `results/filtered_same_scale.csv`
