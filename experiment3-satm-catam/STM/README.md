# STM

This folder contains the paper-facing entry point for the STAM evaluation.

- `run_stam.py`
  - validates and summarizes the packaged STAM results

STAM is the final summed-preference aggregation method used in the paper.

For the reviewer packet, the precomputed STAM results used by the final table live in:

- `results/reviewer_composition_multi_tta_v2.csv`
- `results/filtered_improved_random_substitution.csv`
- `results/stam_filtered_preference_weights_50_50.csv`
